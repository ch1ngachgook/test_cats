# Cat Energy — лендинг функционального питания для котов

Тестовое задание: адаптивная, кросс-браузерная верстка лендинга по макету из Figma.

## Стек и особенности:
- Семантический HTML5 и адаптивный CSS3 (Flexbox, Grid).
- Чистый JavaScript (без сторонних библиотек и фреймворков) для интерактивного слайдера сравнения фото.
- Интеграция официального API Яндекс.Карт.
- Полная адаптивность под мобильные устройства, планшеты и десктопы.
